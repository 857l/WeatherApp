# WeatherApp

Приложение погоды на Kotlin + Jetpack Compose. Поиск города по названию или по GPS-геолокации, текущая погода, почасовой прогноз на сегодня и прогноз на 5 дней вперёд. Данные — с [OpenWeatherMap](https://openweathermap.org/api).

## Возможности

- Поиск города по названию с debounce
- Определение города по текущей геолокации устройства
- Текущая погода: температура, ощущается как, влажность, давление, ветер, порывы, облачность, восход/закат, видимость
- Почасовой прогноз на сегодня c 06:00 до 06:00
- Прогноз на 5 дней
- Локальное кэширование Room
- Автоматическое обновление текущей погоды и прогноза
- Постоянное уведомление с городом, температурой и описанием погоды
- Виджет главного экрана с текущей погодой и шестью ближайшими прогнозными точками

## Стек

- **Язык:** Kotlin 2.0.20
- **UI:** Jetpack Compose, Material3, Navigation Compose 2.9.0
- **DI:** Hilt 2.57
- **Сеть:** Retrofit 3.0.0 + Gson, OkHttp
- **База данных:** Room 2.6.1
- **Изображения:** Coil 2.7.0
- **Геолокация:** Play Services Location 21.3.0
- **Фоновые задачи:** WorkManager 2.10.3
- **Виджет:** Jetpack Glance 1.1.1
- **compileSdk / targetSdk:** 35, **minSdk:** 26

## Запуск

1. Получи бесплатный API-ключ на [openweathermap.org](https://home.openweathermap.org/api_keys).
2. Создай `local.properties` в корне проекта и добавь строку: `OWM_API_KEY=твой_ключ_сюда`
3. Собери и запусти как обычный Android-проект
